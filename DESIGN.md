# ethan. / Personal publication
Brief: A personal website about AI tool experiments, technology and everyday observations. Only existing approved writing; no invented career, project or audience metrics. Independent pages; home is a single cover. Existing React/Vite homepage and Python CMS stay.
Concepts considered (originality / fit / feasibility / portability; lower portability is better):
- Personal publication cover, anchored in the actual first essay about beginning to write. Name becomes the cover image; publication typography continues through article titles. 4/5/5/3. Chosen for expressive static composition and honest content.
- Lab notebook, anchored in AI tool experiments. Tabbed notes and technical annotations. 3/4/5/4. Rejected as too close to developer templates.
- Literal name monogram, anchored in ethan. An oversized e becomes the layout. 4/3/4/3. Rejected because decorative shape has little relation to writing.
Concept: a personal publication with a bold mustard cover, direct page index, and large ink-black name.
Signature: name as image, occupying the lower third. Links invert like inked print blocks on interaction. Still at rest by explicit choice: user wants animation removed.
Palette: cover #e7ba42; ink #24221e; paper #f6f4ee; secondary #655f55; rule #bcb7aa.
Type: Arial/Helvetica for Latin, PingFang SC/Microsoft YaHei for Chinese, all local system fonts. Heavy compact display; 17–18px reading text; genuine article dates.
Grid: asymmetric two-column cover over a single huge wordmark; mobile stacked cover with compact index; subpages broad colored mastheads and restrained reading columns. No cards, arrows, footage, gradients, or scroll sections on home.
Home: header / [statement | page index] / oversized ethan. / colophon.
Subpages: shared header / oversized title / page-specific reading or index layout / common footer.
Genericness review: removed cinematic hero, stock character, decorative numbering and serif slogan treatment. Typography and flat field color carry the identity. No loaders or automatic motion; native links retain keyboard focus and whole-row hover fill.

Independent screenshot critic: Design 7.4, Usability 7.0 (visual only), Creativity 6.5, Content 6.5; weighted ~7.0. It called the idea an editorial cover, matching the concept. Applied its concrete improvement to about-page composition. Rejected suggested arrows because of the user's established preference. Content limits are real: one published essay and an approved short biography; no invented achievements or projects. Formal axe/performance audits were not run; browser layout, focus, copy interaction and CMS regression checks provide bounded evidence.
